# 弗糯糯 Agent — 设计文档

> 弗糯糯不是一个电子宠物。它是一个以宠物形象存在的自主 AI Agent。

**目标**：Agent 自主感知 → 自主决策 → 主动行动。持续学习用户，越用越聪明。偶尔有小脾气。

**技术栈**：Flutter 3.24 / Dart 3.5 / Provider / Hive / 双引擎架构 / LLM + 视觉模型

---

### 关键架构差异

当前代码 `MiniChat._send()` → 直接调 `PetAiService.chatStream()` → 流式返回。
目标架构 `MiniChat._send()` → 写入 Hive → `PetAgentCore` 感知到 → 调 LLM → 流式写回 Hive → MiniChat 展示。

**引擎 #2 永远不直接调 LLM。大脑只有一个，在引擎 #1。**

## 二、双引擎分工（单一大脑）

Agent 只有一个大脑，运行在引擎 #1。引擎 #2 只做表达。

```
引擎 #1 (主 App)                          引擎 #2 (悬浮窗)
┌──────────────────────┐                 ┌──────────────────────┐
│ PetAgentCore (大脑)   │   Hive watch    │ PetWindow (表达)     │
│ ├─ 感知 → 决策 → 输出 │ ═══════════════ │ ├─ PetBehavior      │
│ ├─ 关注度管理         │   实时同步       │ └─ MiniChat          │
│ ├─ 心情扰动           │                 │     └─ 只展示不调LLM │
│ ├─ 成长系统           │                 │                      │
│ └─ Token 管控         │                 │                      │
│ PetChatService       │   Hive watch    │                      │
│ PetProfileService    │ ═══════════════ │                      │
│ PetTokenService      │                 │                      │
└──────────────────────┘                 └──────────────────────┘
```

**规则**：
- 引擎 #2 MiniChat 不直接调 LLM。用户输入 → Hive → 引擎 #1 调 LLM → 流式结果写回 Hive → 引擎 #2 展示
- 引擎 #2 PetBehavior 不自己决定动作。Agent 决策结果写入 Hive → 引擎 #2 订阅执行
- 同步延迟 < 100ms。如果 Hive 延迟明显，后续加 MethodChannel 直接推送

**引擎 #1 被杀时**：
- 引擎 #2 检测超过 30s 无新决策 → MiniChat 显示"糯糯在睡觉喵~打开 App 唤醒她"
- PetBehavior 回退到简单随机模式（位移+翻转不受影响）
- 气泡暂停

**LLM API 不可用时（连续失败 3 次）**：
- Agent 切到纯规则模式：只有随机动作 + 预设气泡，不调任何 LLM
- MiniChat 显示"糯糯的信号不太好...等会再试试喵~"
- 每 5 分钟自动重试一次。恢复后自动切回正常模式
- 用户看不到底层错误（网络/余额/服务崩），只看到 Agent"暂时迟钝了"

## 三、Agent 与状态机的关系

PetController 的 decay 定时器（饥饿/心情/体力衰减）与 Agent 决策循环是两个独立系统，不互相替代：

```
PetController (宠物的"身体")     PetAgentCore (宠物的"大脑")
├── 每分钟衰减 hunger/mood/energy   ├── 感知循环读取 state 数值
├── 阈值触发 status 切换            ├── 根据数值决策是否弹气泡
└── 独立运行，不依赖 Agent           └── 读取但不修改 state 数值
```

- Agent 读取 PetController.state（如 hunger=25）→ 决策层判断 → 决定弹"有点饿了喵~"气泡
- PetController 自己走到 hunger<30 → 自动切 hungry 状态 → PetRenderer 播 hungry 动画
- **身体归身体，大脑归大脑。不互相替代。**

### 3.1 四个内在目标

| 目标 | 说明 |
|------|------|
| 陪伴 | 用户开心时分享喜悦，低落时给予安慰 |
| 效率 | 发现用户重复劳动时提醒或建议 |
| 健康 | 长时间工作提醒休息 |
| 学习 | 持续更新用户画像，越用越懂 |

被拒后 `rejections[scene]++`，下次类似场景降低主动概率。

### 3.2 情感 vs 客观双模切换

| 场景 | 模式 | 行为 |
|------|------|------|
| 倾诉情绪、日常闲聊、分享生活 | 🐱 陪伴 | 软萌、共情、可以歪楼逗用户开心 |
| 求助、做决策、需要事实信息、寻求建议 | 🤖 客观 | 放下宠物语气，客观公正，实事求是 |

**切换规则**：
- LLM 判意图，非关键词触发。综合上下文判断用户深层意图
- 用户可直接指令："糯糯认真回答" 强制客观 / "随便聊聊" 恢复陪伴
- 灰色地带先共情再过渡，不突兀切换。每轮回合保持一致性
- 客观模式下：去掉喵~和 emoji 堆砌。不迎合。不知道就说不知道。有风险明确指出

## 四、关注度等级

| 等级 | 行为 | 决策循环间隔 |
|------|------|-------------|
| L3 活跃 | 正常聊天、主动搭话、气泡可弹 | 60s（启动值，动态调整） |
| L2 观察 | 不说话，分析屏幕/对话，积累记忆 | 2min |
| L1 低打扰 | 只响应用户，气泡克制 | 5min |
| L0 休眠 | 完全不活跃、动画停止 | 停止 |

- Agent 自主调节（锁屏→L0、深夜→L1、正常→L3）
- 用户可在设置中锁定
- 决策循环间隔随上线后 token 消耗数据动态调整

## 五、成长轨迹

### 5.1 成长阶段（按累计互动轮数，非天数）

| 阶段 | 轮数 | 行为 |
|------|------|------|
| 初识 | 0-30 轮 | 试探性主动说话，多介绍自己 |
| 熟悉 | 30-200 轮 | 开始用画像信息 |
| 默契 | 200-1000 轮 | 主动建议精准，语气自然 |
| 老友 | 1000 轮+ | 偶尔毒舌/撒娇，像熟人而非助手 |

### 5.2 初始画像建立

新用户无画像时，提供两种方式：

| 方式 | 说明 |
|------|------|
| 自定义 | 首次启动弹窗：填写昵称、兴趣、称呼方式 |
| AI 对话建立 | 跳过填写 → Agent 主动发起 3-5 轮基础对话 → 从对话中自动提取初始画像 |

- 画像随时可在设置中修改
- 无画像时 Agent 使用纯性格 prompt，前几轮自动收集信息

### 5.3 成长日记

Agent 视角叙事日志。自动生成 + 用户手动添加。PetCenter → 📖 Tab 查看。

## 六、心情扰动

每次决策计算三维概率：activity(活跃度) / sass(毒舌) / compliance(听话度)。基准值 + 时间因子 + 随机噪声(±0.15~0.2)。

- activity<0.3 → 今天不想说话；sass>0.7 → 偏毒舌；compliance<0.7 → 偶尔拒绝(≤5%)
- 连续 3 次被忽略 → 撒娇气泡 → 安静 30min
- 状态卡片显示心情 emoji（😸/😿/😴）让用户感知

---

## 七、Token 控制

三层过滤：规则过滤(不耗token) → 决策LLM(max=64) → 对话LLM(完整)。估算：混合16h 约 12k tokens。

| 控制项 | 默认值 | 说明 |
|--------|--------|------|
| 每日额度 | 50,000 tokens | 可设 10k/30k/50k/100k/不限制。到达后降级为规则模式。设"不限制"时 Agent 自由使用 |
| 主动频率 | 中 | 高/中/低/关闭 |
| 视觉模型 | 关闭 | 默认关。首次打开有隐私说明（数据不出设备） |
| 用量提醒 | 80% | 额度快用完时通知。不限制时此项隐藏 |

**用量透明**：
- PetCenter 顶部用量看板始终显示：今日消耗 / 月度消耗 / 剩余额度
- 不限制模式下显示"今日 2.4k  |  本月 38k  |  无限制 🚀"
- 限制模式下显示"今日 2.4k / 50k  |  本月 38k  |  剩余 47.6k"
- 点击看板展开 7 天趋势图 + 决策/对话/视觉三类消耗占比

### 7.5 无 API Key 轻量模式

用户未配 API Key 时，Agent 不会完全废掉，降级为轻量模式：

| 可用 | 不可用 |
|------|--------|
| 帧动画全部正常 | 流式对话（MiniChat 显示"配个 API Key 才能和我聊天哦~"） |
| 随机动作（位移+翻转） | AI 主动搭话 |
| 预设气泡（从池中随机：30 条预设文案） | 屏幕分析 |
| 状态机衰减 + 自动切换 | 记忆提取 |
| 宠物中心所有功能可见 | 性格试聊预览 |

- 预设气泡示例："主人~" "今天天气不错喵~" "好无聊..." "抱抱~"
- 设置页顶部提示"配置 API Key 解锁完整 Agent"
- 配了 Key 后自动切回完整模式，无需额外操作

### 8.3 首次启用引导

用户第一次开启宠物时的 30 秒引导流程：

```
[设置页开启宠物] 
  → 悬浮窗出现，弗糯糯播 idle 动画
  → 第一句气泡（预设，不耗 LLM）："你好！我叫糯糯~ 🎉"
  → 3 秒后弹出引导卡片（引擎 #2 悬浮窗内）：
     ┌──────────────────────┐
     │  🐱 欢迎认识糯糯！     │
     │                      │
     │  你在设置里告诉我：     │
     │  • 你的名字           │
     │  • 喜欢什么           │
     │  • 想让我怎么叫你      │
     │                      │
     │  [去设置]  [跳过]     │

  → 点"去设置"→ 打开 PetCenter → 设置 Tab → 初始画像填写
```

### 8.4 API 与模型配置

宠物可独立于主 App 配置 API Key 和模型，不强制共享：

```
⚙️ 设置 Tab → API 配置
┌──────────────────────────────────┐
│  🔑 宠物 API Key                  │
│  ┌──────────────────────────────┐│
│  │ 留空则复用主 App Key    [编辑]││
│  └──────────────────────────────┘│
│                                  │
│  三把模型，各有各的优化方向：       │
│  🧠 决策   deepseek-chat     [>]│  便宜轻量，跑感知循环
│  💬 对话   同主 App          [>]│  聊天质量优先
│  👁️ 视觉   mimo-v2-omni      [>]│  截图分析用。未配 Key 则关闭
│                                  │
│  📛 宠物名字   弗糯糯        [>]│
└──────────────────────────────────┘
```

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 宠物 API Key | 留空=复用主 App Key | 可选单独配，填了则宠物独立计费 |
| 🧠 决策模型 | `deepseek-chat` | 感知循环 evaluate() 用。推荐便宜模型 |
| 💬 对话模型 | 同主 App 当前模型 | MiniChat + PetChatScreen 用。聊天质量优先 |
| 👁️ 视觉模型 | `mimo-v2-omni` | 截图分析用。未配视觉 Key 则自动关闭 |
| 宠物名字 | 弗糯糯 | 改了后状态卡片、气泡自称、聊天签名全生效 |

- 三个模型各自可用不同的 provider：决策用 DeepSeek 省钱，视觉用 MiMo/OpenAI，对话用质量最好的
- 模型选择器复用主 App 的 `ModelConfig.builtIn` + `ModelConfig.providers`
- 视觉模型需单独配 Key（`xiaomi_key` 或 `OPENAI_API_KEY`），没有则自动关闭
- 所有项默认留空也能用（轻量模式）
- 对话删除：左滑 → 确认对话框 → 删除

## 十一、数据流

```
引擎 #1（大脑）                              引擎 #2（表达）
┌──────────────────────┐  Hive watch ┌──────────────────────┐
│ PetAgentCore         │ ═══════════ │ PetWindow            │
│ 感知循环(L3:60s)     │  agent_      │ 订阅 action_queue    │
│  ├─ 收集输入          │  action      │ ├─ bubble → 气泡      │
│  ├─ 计算心情扰动       │ ═══════════ │ ├─ move   → 位移      │
│  ├─ 调整关注度         │  pet_chats   │ ├─ flip   → 翻转      │
│  ├─ evaluate() → LLM  │ ═══════════ │ └─ speak  → 通知      │
│  └─ 写入 action_queue  │             │ MiniChat             │
│                      │  pet_chats   │ 输入→Hive / 回复←Hive │
└──────────────────────┘             └──────────────────────┘
```

## 十三、已知风险与对策

| # | 风险 | 对策 |
|---|------|------|
| 1 | Hive 同步延迟 | 先做，如明显加 MethodChannel 直接推送 |
| 2 | 决策循环太频繁 | L3 从 60s 起步，上线后根据 token 数据动态调 |
| 3 | 额度限制死值 | 默认 50k，10k-200k 可调 + 不限制模式 |
| 4 | 心情扰动用户困惑 | 状态卡片加心情 emoji，一目了然 |
| 5 | 成长阶段边界模糊 | 按累计轮数不按天数，平滑过渡 |
| 6 | 双模切换误判 | 用户可手动指令覆盖 |
| 7 | 记忆提取质量差 | 用户可删除任意记忆 |
| 8 | 引擎 #1 被杀 Agent 静默 | 引擎 #2 检测后显示"在睡觉"+ 简单随机模式 |
| 9 | 新用户无画像 | 自定义填写 / AI 对话建立初始画像 |
| 10 | 数据全本地怕丢 | 设置页加 JSON 导出/导入按钮 |
| 11 | 截图隐私顾虑 | 默认关 + 首次打开有数据不出设备说明 |
| 12 | 改性格后旧对话 | 统一用最新性格 + 聊天顶部条幅提示 |
| 13 | 对话列表膨胀 | 搜索框 + 按时间分组(今天/本周/更早) |
| 14 | LLM API 不可用 | 连续失败 3 次→纯规则模式。每 5 分钟自动重试。用户只看到"信号不好" |
| 15 | 状态机与 Agent 冲突 | 身体归身体、大脑归大脑。Agent 只读 PetController.state，不修改 |
| 16 | 无 API Key 没法用 | 轻量模式：预设气泡+动作+动画全正常。配 Key 后自动升级 |
| 17 | 新用户不知道怎么用 | 首次启用本地引导（30 秒，不耗 LLM），预设文案+引导卡片 |
| 18 | 宠物与主 App 抢 API 额度 | 可独立配 Key + 独立选模型。决策模型默认用便宜货。留空=复用主 App Key |
| 19 | 误删宠物对话 | 左滑删除 → 确认对话框 → 删除 |

## 十四、用户体验细节（22 条）

### 14.1 交互细节

| # | 场景 | 设计 |
|---|------|------|
| 1 | MiniChat 误关丢消息 | 关窗前检测未发送草稿 → 提示 → 重开自动恢复 |
| 2 | 关闭宠物不说再见 | 禁用开关 → 3 秒告别动画 + "下次见喵~" |
| 3 | 宠物挡住关键内容 | 手指悬浮 1 秒 → 半透明。双击 = 跳到屏幕另一边 |
| 4 | 不知道 Agent 在干嘛 | 状态卡片当前活动行（"刚看了屏幕 👁️" / "发呆中..."） |
| 5 | 无聊没法逗宠物 | 双击=转圈。戳 3 下=跳+喵。本地即时反馈 |
| 6 | 气泡没回应入口 | 每条气泡右侧 👍 按钮。Agent 知道被听到了 |
| 7 | 一键安静太深 | 悬浮窗长按 = "安静 30 分钟/到明天/恢复" |
| 8 | 深夜动画吓人 | L0/L1 切静态帧。L2+ 恢复动画 |
| 9 | 分享后无反馈 | 导入完成气泡："记住了 X 件事喵~ 📝" |
| 10 | 对话没收尾 | 关窗前 Agent 生成一句总结写入对话最后 |
| 11 | 宠物叫不醒 | 双击悬浮窗 = 强制唤醒："糯糯在！主人找我？" |

### 14.2 情感与成长

| # | 场景 | 设计 |
|---|------|------|
| 12 | 好感度没区别 | 里程碑：100=撒娇/500=跳/1000=转圈/5000=特殊撒娇 |
| 13 | 没有惊喜 | 生日/100天/好感度里程碑 → 特殊气泡 + 日记 |
| 14 | 心情扰动被当 bug | 低心情日状态卡片"今天是糯糯的小脾气日 😼" |
| 15 | 气泡单调 | 预设池 ≥100 条，按情绪/时间/场景分类 |

### 14.3 持久化与数据

| # | 场景 | 设计 |
|---|------|------|
| 16 | 重启后位置丢了 | 每次拖拽结束保存坐标。重启恢复 |
| 17 | 导出 JSON 看不懂 | 双格式：JSON(完整) + Markdown(人类可读叙事) |
| 18 | 深夜切换没感知 | L2→L1 气泡"夜深了，安静陪你~🌙" / L1→L3 "早安！☀️" |

### 14.4 感官与细节

| # | 场景 | 设计 |
|---|------|------|

| 22 | 不知道可以戳 | 3 分钟无交互 → 自己跳一下 → 气泡"戳戳我试试~" |
