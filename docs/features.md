# 你的桌面小精灵，随时随地陪伴你

**它会出现在你的手机屏幕上，任何 App 上层。** 无论你在刷微信、看网页、还是发呆，它都在那里。戳它、喂它、和它聊天——它会记住关于你的一切，慢慢成为最懂你的小东西。

---

## 它会做什么

### 🐾 随时在你身边

不是塞在 App 里需要你点开的宠物。它直接漂浮在屏幕上，微信上面、浏览器上面、桌面上——你干什么它都在。戳一下会跳，摸一摸会开心，三连击它就会变透明不挡你。

### 💬 会跟你聊天

双击它，弹出一个迷你聊天窗。不用切 App，直接聊。你说什么它都回，而且**回复不是预设好的——它真的在用 AI 理解你在说什么。**

### 🧠 会记住关于你的事

你告诉它的事、它观察到的习惯，它都记着。

比如你每天早上喝咖啡、下午三点会休息、最近在学日语——它会自己整理成一幅你的画像。这些记忆你随时可以看、可以搜、可以删。

### 📖 会自己写日记

你每次摸它、喂它、跟它聊天，它都会记进日记里。按天排列，带时间戳。就像一本你和它一起写的小日记本。

### 💡 会主动关心你

不是等你去问它。早上它会跟你说早安，深夜会提醒你睡觉，周末会问你要不要看看这周的日记总结。不是烦人的通知——是气泡，轻轻冒出来，看一眼就没了。

---

## 它是什么样的性格

**你自己定。**

在设置里写一段提示词，它就按你说的来：

> "你是一只懒散的橘猫。自称本喵，句尾加喵。不爱动，喜欢吐槽主人。"

或者：

> "你是一个高冷的白猫。话少、精准、不说废话。主人遇到问题时才开口。"

名字、自称、语气——全部你说了算。改一次，整个 App 里所有地方都跟着变。

---

## 它安全吗

- **数据全在手机里。** 对话、记忆、日记——不经过任何服务器。
- **API Key 你自己填。** 不让任何人替你付费，也不用担心别人看到你的对话。
- 不想留的东西，随时删。

---

## 怎么开始

1. 打开 App，进入「宠物中心」
2. 点「编辑人格」——给你的宠物取名字、写性格
3. 开启悬浮窗权限
4. 回到桌面，它就在那里了

---

## 快速上手指南

| 你想做什么 | 怎么做 |
|------|------|
| 给它取名字 | 宠物中心 → 设置 → 编辑人格 |
| 教它怎么说话 | 编辑人格 → 人格提示词 |
| 跟它聊天 | 屏幕上双击它 |
| 看它记住了什么 | 宠物中心 → 记忆与日记 → 记忆 |
| 看互动日记 | 宠物中心 → 记忆与日记 → 日记 |
| 让它安静一点 | 宠物中心 → 设置 → AI 频率 → 安静 |
| 控制花费 | 宠物中心 → 设置 → Token 管理 |
| 导出聊天记录 | 主页面侧边栏 → 长按对话 |

---

*它会慢慢认识你——你爱吃什么、几点睡觉、喜欢谁的音乐。不是一次性设置好的机器人，而是一天天养出来的小伙伴。*
