现在决定：四大方向怎么排优先级？

每个方向代表不同的产品形态。选 3 个排 1st / 2nd / 3rd

A

AIRI 式交互深度

Live2D 动态角色 + 语音对话 + 拖拽悬停效果 + 多窗口系统。角色表现力最强，开发成本最高（1-2 个月）

✓ 可得

  • 角色活起来
  • 自然交互
  • 竞争力强

✗ 代价

  • 需 Electron/Tauri
  • 与当前 Kotlin 路线不同
  • 移动端受限
B

Codex Pets 式 Agent 集成

宠物=AI 状态指示器。动画映射 LLM 阶段。点宠物→回 AI。共鸣最强，与现有 LLM 管道深度整合

✓ 可得

  • 减少等待焦虑
  • 复用现有 LLM API
  • 差异化定位

✗ 代价

  • 需改造 DeepSeek client
  • 流式状态回调
  • 场景需打磨
C

Petdex 式生态开放

pet.json 皮肤系统 + 多角色切换 + CLI 导入。社区兼容，用户自创/分享宠物

✓ 可得

  • 无限内容
  • 社区驱动
  • 格式已对齐

✗ 代价

  • 需要皮肤管理 UI
  • 导入验证逻辑
  • 跨宠物兼容
D

当前 Spec 养成深化

完善状态机闭环 + AI 日记/记忆 + 迷你聊天。情感粘性最强，基础体验完整

✓ 可得

  • 养成闭环
  • 情感连接
  • 已有 UI 基础

✗ 代价

  • 原子化状态机逻辑复杂
  • Flutter↔原生通信量大
  • AI 日记需要截图管线

🔢 终端回复格式示例：B > D > A（Agent 集成第一、养成深化第二、交互深度第三）
