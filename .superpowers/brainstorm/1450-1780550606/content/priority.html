第 1 步：确定优先级

四个方向各有精华。你心中最重要的 Top 3 怎么排？

A

AIRI 式交互深度

Live2D/VRM 动态角色 + 语音对话 + 拖拽/悬停效果 + 多窗口系统。角色表现力最强，开发成本最高。

B

Codex Pets 式 Agent 集成

宠物作为 AI 工作状态指示器，动画映射 LLM 调用阶段（思考→run、出错→failed、完成→wave），点击宠物→回复 AI。

C

Petdex 式生态开放

多皮肤/多角色支持 + pet.json 导入 + CLI 工具链。用户可切换不同宠物，兼容社区 spritesheet 标准，可提交到 Petdex 画廊。

D

当前 Spec 养成深化

完善 hunger/mood/energy/affection 状态机，喂食/玩耍/睡觉/摸摸闭环，AI 日记/记忆时间线。做深养成体验。

🔢 选 3 个并排优先级（1st / 2nd / 3rd）— 在终端回复，如 "B > A > D" 或 "A first, C second, D last"
