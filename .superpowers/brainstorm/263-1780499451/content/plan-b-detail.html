实现要点

组件NestedScrollView + SliverAppBar
展开高度约 210dp（猫56px + 名字 + 状态 + 4按钮 + TabBar）
收起高度约 100dp（AppBar一行 + TabBar）
猫 emoji 安全兜底：🖼️ Image.asset 或 Icon(Icons.pets) 当 emoji 渲染失败时
Tab Bar始终 pinned 在底部（SliverPersistentHeader）
互动按钮放在 FlexibleSpaceBar 内，随滚动收起
滚动同步TabBarView 内各列表独立滚动，收起/展开由各自列表驱动

交互细节

  • 进入宠物中心 → 展开态，看完整猫卡片
  • 下滑 Tab 内容 → 猫卡片逐渐收起，AppBar 从"🐾 宠物中心"变成"🐱糯糯 🍖80 😊60 ⚡75 ❤️50"
  • 上滑到顶 → 卡片重新展开，看到 4 个互动按钮
  • 切 Tab → 保持当前展开/收起状态
