为什么 Custom View 不会有黑屏问题

SurfaceView 的黑屏和 Custom View 的透明是两回事

❌ SurfaceView 为什么黑
根因：独立窗口层

① SurfaceView 在 Window 下面
   挖了一个"洞"
② SurfaceView 自己的 Surface
   在洞下面渲染
③ 如果 z-order 不对 → 黑
④ 如果透明没配好 → 黑
⑤ 如果 WindowManager 冲突 → 黑

三层都容易出问题
✅ Custom View 为什么不会
普通 View，只有一层

① WindowManager 创建透明窗口
   (PixelFormat.TRANSLUCENT)
② Custom View 作为窗口的唯一子 View
③ onDraw 里 drawColor(CLEAR) → 透明
④ 画 Bitmap → 宠物

没有"洞"，没有独立 Surface，没有 z-order冲突

只有一层窗口 → 要么透明、要么显示

防黑三条保险

// ① 窗口级：PixelFormat.TRANSLUCENT（现有代码已有，保留）
val params = WindowManager.LayoutParams(
    ...
    PixelFormat.TRANSLUCENT   // ← 窗口本身支持透明
)

// ② View级：标记为非不透明
class PetView(context: Context) : View(context) {
    init {
        setLayerType(LAYER_TYPE_HARDWARE, null)
        setBackgroundColor(Color.TRANSPARENT)  // ← View 背景透明
        // 不需要这个：isOpaque 默认为 false（View 默认透明）
    }
}

// ③ Canvas级：每帧清空到透明
override fun onDraw(canvas: Canvas) {
    canvas.drawColor(0, PorterDuff.Mode.CLEAR)  // ← 清空为完全透明
    // ... 画宠物 ...
}
⚠️ 唯一需要注意的：如果将来给 PetView 的父容器（FrameLayout/rootView）设置了背景色，会挡住透明。
当前代码里 rootView 是 FrameLayout，没有设置背景色 → 默认透明 → 没问题。

验证方法

改完后只需验证一个场景：打开宠物 → 切到桌面 → 宠物浮在桌面上，周围是桌面背景而非黑色方块。
如果看到宠物的矩形边界有黑边，检查上面三条保险的任意一条即可。
