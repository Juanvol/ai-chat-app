核心组件详解

1. SurfaceView 渲染循环 (60fps)

替换 ImageView + Handler。独立的 Surface 在自己的线程上渲染，不阻塞 UI 线程：

class PetRenderer(surface: SurfaceView) {
    // 60fps 渲染循环
    fun start() {
        Thread {
            while (running) {
                val canvas = surfaceHolder.lockCanvas()
                canvas.drawColor(0, PorterDuff.Mode.CLEAR) // 透明背景
                petSprite.draw(canvas)     // 绘制当前帧
                bubble.draw(canvas)        // 绘制气泡
                physics.update(deltaTime)  // 更新物理位置
                surfaceHolder.unlockCanvasAndPost(canvas)
                sleep(16) // ~60fps
            }
        }.start()
    }
}

2. 轻量物理引擎 (~150行)

物理属性公式/值效果
重力vy += 980 * dt被扔出后下落
边界碰撞if (x < 0) { x=0; vx*=-0.6 }碰到屏幕边缘弹回
弹性挤压scaleX = 1 + (abs(vx)/2000)落地时变扁，跳起时变长
拖拽惯性vx = (x - prevX) / dt松手后继续飞
摩擦力vx *= 0.95; vy *= 0.95自然减速停止

3. 帧插值混合

从 A 动画切换到 B 动画时，不是硬切而是：A 淡出 + B 淡入，交叉时间约 200ms。解决"动画切换生硬"的问题

替换 TextView 的 VISIBLE/GONE 硬切：Alpha 淡入(200ms) + 弹性缩放(scale 0→1.1→1.0, 300ms)，消失同理
